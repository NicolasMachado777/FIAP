Aula introdução ao Dart:

Dart é uma linguagem de script voltada à web desenvolvida pela Google. 
Ela foi lançada na GOTO Conference 2011, que aconteceu de 10 a 11 de outubro de 2011 em Aarhus, na Dinamarca. 
O objetivo da linguagem Dart foi inicialmente a de substituir a JavaScript como a linguagem principal embutida nos navegadores.

Para criar o dart, seguimos os seguintes passos:

dart create (nome)
cd (nome)
code . //esse é para abrir o Vs e já abrir o documento criado.
