Usamos JUnit com Java.
  O JUnit é um framework open-source, que se assemelha ao raio de testes software java, 
  criado por Erich Gamma e Kent Beck, com suporte à criação de testes automatizados na linguagem de programação Java. 
  Esse framework facilita a criação e manutenção do código para a automação de testes com apresentação dos resultados.

Nesta aula tivemos o primeiro contato com o teste no Java.
Para habilitar o JUnit no VS, preciso digitar > e procurar por test, depois digitar @test e assim o codigo a ser testado.

Sempre assim:
@test
codigo
@test
codigo
....

Nesta aula fizemos uma Caculadora-Paraguaya, para fazer os testes.
  Calculadora não funcional, somente para testes usando o jUnit
